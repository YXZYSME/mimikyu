# `mimikyu-cli`

Official CLI & MCP binary distribution for [`mimikyu`](https://github.com/YXZYSME/mimikyu) (also published as [`saengil-mimikyu`](https://www.npmjs.com/package/saengil-mimikyu) and [`mimikyu-mcp`](https://www.npmjs.com/package/mimikyu-mcp)).

## Install & Usage

```sh
# Install the `mimikyu` CLI binary globally
npm install -g mimikyu-cli
mimikyu doctor

# Or run directly without global install via npx
npx -y mimikyu-cli doctor
```
